# blinds-flipbook
To embed flipbook using iframe
```html
<!-- To embed it to website via iframe -->
<div style="width: 100%; height: 500px; overflow: hidden;">
    <iframe height="500" width="100%"
        src="https://ahmed-jibran.github.io/blinds-flipbook/"
        allowfullscreen=""
        frameborder="0"
        scrolling="no"
        seamless="seamless">
    </iframe>
</div>
```
